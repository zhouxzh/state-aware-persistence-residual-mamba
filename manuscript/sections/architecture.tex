\section{Neural Network Architecture}

\subsection{Input and Tensor Shapes}

The implementation uses tensors of shape $\mathbb{R}^{B \times L \times C}$, where $B$ is batch size.
For GLD, $C=1$.
After adaptive normalization and optional decomposition, each component is passed to an inverted embedding layer.
The embedding maps temporal history into hidden dimension $d_{\mathrm{model}}$.
In the locked GLD setting, $d_{\mathrm{model}}=64$ and the feed-forward dimension is 128.

\subsection{S\_Mamba Encoder}

The S\_Mamba backbone applies bidirectional Mamba encoder layers to the embedded representation.
A simplified state-space update is:
\begin{equation}
    \mathbf{h}_t
    =
    \mathbf{A}(\mathbf{x}_t)\mathbf{h}_{t-1}
    +
    \mathbf{B}(\mathbf{x}_t)\mathbf{x}_t,
    \qquad
    \mathbf{o}_t
    =
    \mathbf{C}(\mathbf{x}_t)\mathbf{h}_t.
\end{equation}
The input-dependent matrices give Mamba a selective memory mechanism.
NS-Mamba preserves this mechanism and adds explicit nonstationary conditioning before and around the encoder.

\subsection{Variant Definitions}

This repository contains several Mamba-family variants.
The names encode which nonstationary modules are active.
\textbf{A} denotes adaptive normalization, \textbf{D} denotes trend--seasonal--residual decomposition, and \textbf{G} denotes shift-aware gated fusion.
\textbf{M} denotes multi-scale temporal branches, \textbf{S} denotes an NLinear-style residual skip, and \textbf{P} denotes patch-temporal Mamba branches.
All variants produce forecasts with shape $\mathbb{R}^{B \times H \times C}$ and use reversible output scaling when normalization is enabled.

Let
\begin{equation}
    \mathcal{N}(\mathbf{X})
    =
    \frac{\mathbf{X}-\boldsymbol{\mu}}{\boldsymbol{\sigma}+\epsilon},
    \qquad
    \mathcal{N}^{-1}(\mathbf{Z})
    =
    \mathbf{Z}\odot(\boldsymbol{\sigma}+\epsilon)+\boldsymbol{\mu},
\end{equation}
where $\boldsymbol{\mu}$ and $\boldsymbol{\sigma}$ are computed from the input window.
Let $\mathcal{F}_{\theta}(\cdot)$ denote one inverted Mamba forecasting branch, including inverted embedding, bidirectional Mamba encoding, and horizon projection.
The S\_Mamba baseline is therefore:
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{S}}
    =
    \mathcal{N}^{-1}
    \left(
    \mathcal{F}_{\theta}(\mathcal{N}(\mathbf{X}))
    \right).
\end{equation}

\paragraph{Adaptive-normalization variants.}
NS-Mamba-A replaces fixed normalization with adaptive normalization:
\begin{equation}
    \mathcal{N}_{A}(\mathbf{X})
    =
    \boldsymbol{\gamma}(\phi(\mathbf{X}))
    \odot
    \mathcal{N}(\mathbf{X})
    +
    \boldsymbol{\beta}(\phi(\mathbf{X})),
\end{equation}
where $\phi(\mathbf{X})$ contains window shift statistics such as mean shift, variance shift, slope, range, and recent volatility.
The forecast is:
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{A}}
    =
    \mathcal{N}_{A}^{-1}
    \left(
    \mathcal{F}_{\theta}(\mathcal{N}_{A}(\mathbf{X}))
    \right).
\end{equation}
This variant tests whether a learned normalization transform alone is enough to improve nonstationary forecasting.

\paragraph{Decomposition variants.}
NS-Mamba-D first applies standard reversible normalization and then decomposes the normalized signal:
\begin{equation}
    \mathbf{Z}=\mathcal{N}(\mathbf{X}),
    \qquad
    (\mathbf{Z}^{\mathrm{tr}}, \mathbf{Z}^{\mathrm{se}}, \mathbf{Z}^{\mathrm{re}})
    =
    \mathcal{D}_{m}(\mathbf{Z}),
\end{equation}
where $\mathcal{D}_{m}$ is a moving-average decomposition with window size $m$.
The three components represent trend, seasonal or medium-frequency variation, and residual variation.
The decomposition forecast is:
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{D}}
    =
    \mathcal{N}^{-1}
    \left(
    \sum_{q \in \{\mathrm{tr},\mathrm{se},\mathrm{re}\}}
    \mathcal{F}_{\theta_q}(\mathbf{Z}^{q})
    \right).
\end{equation}
NS-Mamba-AD uses the same branch structure but replaces $\mathcal{N}$ with $\mathcal{N}_A$.

\paragraph{Shift-gated variants.}
NS-Mamba-ADG adds a shift-aware fusion gate to the adaptive decomposition branches.
For component forecasts $\mathbf{U}_q=\mathcal{F}_{\theta_q}(\mathbf{Z}^q)$, the gate is:
\begin{equation}
    \boldsymbol{\alpha}
    =
    \operatorname{softmax}
    \left(
    g_{\psi}(\phi(\mathbf{X}))
    \right),
    \qquad
    \sum_q \alpha_q = 1,
\end{equation}
and the forecast is:
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{ADG}}
    =
    \mathcal{N}_{A}^{-1}
    \left(
    \sum_{q}
    \alpha_q \odot \mathbf{U}_q
    \right).
\end{equation}
This variant tests whether distribution-shift statistics can improve how the model combines trend, seasonal, and residual information.

\paragraph{Multi-scale variants.}
The MS-Mamba family adds temporal scale branches.
Let $\mathcal{P}_{s}(\cdot)$ be average-pooling downsampling by scale $s$, and let $\mathcal{S}$ be a set of scales such as $\{1,2,4\}$.
For a decomposition-enabled multi-scale model, each scale produces:
\begin{equation}
    \mathbf{U}_{s}
    =
    \sum_{q \in \{\mathrm{tr},\mathrm{se},\mathrm{re}\}}
    \mathcal{F}_{\theta_{s,q}}
    \left(
    \mathcal{P}_{s}(\mathbf{Z}^{q})
    \right).
\end{equation}
MS-Mamba-MD uses mean scale fusion:
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{MD}}
    =
    \mathcal{N}^{-1}
    \left(
    \frac{1}{|\mathcal{S}|}
    \sum_{s \in \mathcal{S}}
    \mathbf{U}_{s}
    \right).
\end{equation}
MS-Mamba-MDG replaces the mean by shift-aware scale weights:
\begin{equation}
    \boldsymbol{\pi}
    =
    \operatorname{softmax}(g_{\omega}(\phi(\mathbf{X}))),
    \qquad
    \hat{\mathbf{Y}}_{\mathrm{MDG}}
    =
    \mathcal{N}^{-1}
    \left(
    \sum_{s \in \mathcal{S}}
    \pi_s \odot \mathbf{U}_{s}
    \right).
\end{equation}
MS-Mamba-M and MS-Mamba-MG are the corresponding multi-scale variants without the decomposition components.

\paragraph{Linear-skip and patch variants.}
MS-Mamba-MDS adds a last-value residual linear skip:
\begin{equation}
    \mathbf{U}_{\mathrm{skip}}
    =
    \mathbf{x}_{L}
    +
    \mathbf{W}_{\mathrm{skip}}
    (\mathbf{Z}-\mathbf{x}_{L}),
    \qquad
    \hat{\mathbf{Y}}_{\mathrm{MDS}}
    =
    \mathcal{N}^{-1}
    \left(
    \lambda \mathbf{U}_{\mathrm{MD}}
    +
    (1-\lambda)\mathbf{U}_{\mathrm{skip}}
    \right),
\end{equation}
where $\lambda=\sigma(\rho)$ is learned.
PMS-Mamba replaces inverted variable-token branches with patch-temporal Mamba branches.
For patch length $p$ and stride $r$, a scale branch forms patch tokens:
\begin{equation}
    \mathbf{e}_{j}^{(s)}
    =
    \mathbf{W}_{p}
    \operatorname{vec}
    \left(
    \mathcal{P}_{s}(\mathbf{Z})_{j:j+p-1}
    \right),
\end{equation}
then applies Mamba over the patch index $j$.
PMS-Mamba-PD is therefore the patch-temporal counterpart of MS-Mamba-MD.

\subsection{Forecast Head and Loss}

The forecast head projects the final hidden representation to $H$ future values.
The training objective is mean squared error over the forecast horizon:
\begin{equation}
    \mathcal{L}
    =
    \frac{1}{BHC_o}
    \sum_{b=1}^{B}
    \sum_{h=1}^{H}
    \sum_{c=1}^{C_o}
    \left(
    \hat{Y}_{b,h,c} - Y_{b,h,c}
    \right)^2.
\end{equation}
In the current codebase, inverse transformation is enabled by default, so saved predictions, targets, and metrics are reported on the original GLD price scale unless a run uses \texttt{--no-inverse}.
