## 第一部分：这篇论文真正能有的科学意义

### 1. 不能再声称什么

当前稿若作为「提出状态感知 Mamba、证明能处理非平稳」的方法论文，科学上不成立。

- 真实数据几乎没有稳定状态样本，安全性问题不可估计。  
- ETT 仅 2～4 条序列，不能当来源结论。  
- 电力负荷上 Mamba 残差全面差于线性残差，与合成方向相反。  
- 门控在 V2 合成上无增益，V3 符号还反了。  
- 「非平稳」未被测量，只是选用了常被这样称呼的数据集。

这些不是改摘要能补上的。V2/V3 真实表不应再当这篇稿的实证主体。

### 2. 仍能成立的问题（有限、可证伪）

非平稳预测的要点不是换一个更强的编码器，而是：

> 默认应坚持最近观测；只有当**仅用过去**就能认出变化时，才允许学习残差偏离持久性；认不出或处于稳定时，偏离必须能被关掉。

预测形式仍为

\[
\widehat{\mathbf y}_{t+1:t+H}
= x_t\mathbf 1_H + g_t\,\mathbf r_t,
\qquad g_t\in[0,1].
\]

这要求三件可分开检验的事：

1. **残差是否有用：** 在变化已经进入历史之后，非线性残差是否优于线性残差（M2 对 M1）。  
2. **门是否有用：** 在容量匹配下，按状态开关残差是否优于始终打开（M3 对常数门，而不是只对 M2）。  
3. **会不会泄漏或误开：** 变点还在预测窗口内部、历史里还没有信号时，任何模型都不应优于持久性。

科学贡献若存在，是**把「何时偏离持久性」做成可证伪的仿真实验**，而不是报一个真实数据排行榜。真实数据只能在仿真覆盖和泄漏检验通过之后，作为有限的外推案例，不能反过来定义问题。

### 3. 已有仿真为什么不够

V2 合成已经实现了独立序列、已知机制和 M0–M3，但仍有设计缺陷：

| 缺陷 | 后果 |
| --- | --- |
| H1/H2 先对全部变化机制打包 | 看不出跳变、趋势、方差各需要什么模型 |
| 方差变化仍进点预测主表 | 均值路径 RMSE 上本不应预期 M2/M3 必胜 |
| 明确省略「未来才发生的跳变」 | 最要紧的泄漏对照被拿掉了 |
| 门只与 \(g=1\) 的 M2 比 | 多出来的是门参数，不是「按状态开关」 |
| 检测器标签与真实变点关系不是主分析 | 门该开时开没开，没有直接检验 |
| 稳定样本虽有，但未按「检测器也判稳定」设覆盖下限 | 真实数据上后来出现零稳定单元 |

因此需要**新的仿真协议**，而不是在 V2/V3 数字上改分组。

## 第二部分：仿真计划（`sapr_sim_v1`）

### 4. 目标与禁止事项

**目标：** 在生成机制已知的单变量序列上，按机制预先规定谁该赢；看 M0–M3 及匹配门消融是否符合这些规定。

**禁止：**

- 用 V2/V3 测试误差回头选机制、强度或阈值。  
- 把机制打包成一个总冠军。  
- 用真实电力/北京/ETT/金融数字参与本仿真的设计。  
- 读取或混入其他项目的 PEMS、Weather、METR-LA 等。  
- 打断现有进程；GPU 占用时只许排队。开训以问题稿第 20 节为准，无需再授权。

### 5. 模型（结构与已实现 SAPR 一致，比较必须匹配）

| ID | 形式 | 在本仿真中的作用 |
| --- | --- | --- |
| M0 | 持久性 \(x_t\mathbf 1_H\) | 无信号时应赢或持平 |
| M1 | 持久性 + 线性残差 | 水平/趋势类变化的简单对照 |
| M2 | 持久性 + Mamba 残差，\(g=1\) | 始终打开的非线性残差 |
| M3 | 持久性 + 学习标量门 × Mamba 残差 | 候选的状态开关 |
| M3c | 与 M3 同骨干，门为可学习常数 | **H2 的匹配对照**：有门参数、无状态开关 |
| M3sh | 打乱 \(\phi_t\) 与历史配对 | 状态信息是否真被用到 |

M2、M3、M3c 必须同宽、同深、同优化器、同预算。M3 对 M2 只能写成完整路径差异；**门是否按状态工作，主比较是 M3 对 M3c。** 几何与现实现保持一致：两层 Mamba，64/16/4/2，dropout 0.1，AdamW \(3\times10^{-4}\)，batch 64，最多 40 epoch，patience 7。种子新开一组，例如 `{20261101,...,20261105}`，不得沿用已看过结果的 V2/V3 种子。

### 6. 生成器与机制（每条机制预先规定期望）

序列仍独立生成：\(T=2048\)，\(L=384\)，\(H_{\max}=96\)，\(H\in\{12,24,48,96\}\)，季节周期 \(P=48\)。基础过程为 AR + 弱趋势 + 可选季节，创新标准差固定为 1。变点在历史可观测区间内分层抽取，另设泄漏组。强度相对创新标准差，写入配置后不得按误差改。

| 机制 | 生成 | 预先规定的期望 | 若结果相反则意味着 |
| --- | --- | --- | --- |
| S0 纯稳定 | 无变点 | 稳定原点上 M3 相对 M0 的相对 RMSE 不超过 +2%；M3 不得显著差于 M0 | 门关不住或残差乱开 |
| S1 水平跳变 | 变点后加常数 | 变点进入窗口并经过延迟后，M1 应接近或优于 M0；M2 相对 M1 不必大赢 | M2 大赢可能是过拟合，不是「需要 Mamba」 |
| S2 趋势折点 | 变点后斜率改变 | M1 应优于 M0；仅当折点后轨迹明显非线性时 M2 才优于 M1 | 打包进总表会夸大 Mamba |
| S3 方差变化 | 仅改变创新尺度 | **点预测路径 RMSE 上不要求 M2/M3 优于 M0/M1** | 若点预测「大赢」，解释为拟合噪声，不得当非平稳成功 |
| S4 渐进漂移 | 96 步内爬升 | 检测器应滞后；M2 全程开门可能在早期伤 M0；M3 只在滞后结束后优于 M3c | 门若全程≈1，则与 M2 无差别 |
| S5 季节结构变化 | 变点后改变季节项 | 允许 M2 优于 M1；仍须过泄漏检验 | 未过泄漏则不可信 |
| S6 未来跳变 | 变点在原点之后、预测窗内 | **M0 应为最优或并列；M1/M2/M3 不得优于 M0** | 任何显著优于 M0 = 泄漏或乱拟合 |
| S7 弱变化 | 强度低于稳健尺度 | 检测器应判稳定；M3 应接近 M0，不得优于靠「偷看」 | 检测器过敏 |

V2 把「未来跳变」从主分析拿掉，本计划把它列为**必须通过的阴性对照**。过不了 S6，不得讨论状态感知。

每机制--强度：训练/验证/测试 = 200/50/100 条独立序列；S0 为 300/100/200。测试原点间隔 \(H_{\max}\)，以序列为推断单位。

### 7. 标签：真实变点 vs 因果检测器

必须同时保存、不得混用：

- **真实状态：** 由生成器变点与延迟计算。延迟内：历史尚无信号，真实标签为「尚不可见」，评价上并入 S6 逻辑，即不得惩罚模型没预测到未来跳变，也不得奖励猜中。  
- **检测器状态：** \(\max_j|\phi_{t,j}|\ge\tau\)。\(\tau\) 只许用训练序列的检测器分数分位数在训练前锁定（建议训练窗 0.80 分位，并卡在 \([1.5,4]\)），**验证/测试不得重估**。

**开训前覆盖门（不满足则停，不许降阈值凑样本）：**

- 测试集每个机制：真实稳定原点 ≥ 200 条序列；真实「可见变化」原点 ≥ 100 条序列。  
- 检测器稳定与检测器变化同样要达到上述下限。  
- S6 单独满员，不并入「可见变化」主表。

覆盖失败只允许：换生成参数后**重新冻结版本**，或放弃该机制。不许看模型误差后再改 \(\tau\)。

### 8. 主检验（先机制，后描述性汇总）

主指标：原始尺度路径 RMSE。差值 = 左模型 − 右模型，负值有利于左。10,000 次按测试序列配对 bootstrap，95% 区间。Holm 在**预先列出的家族内**校正，不用一个跨机制总 p 值当论文结论。

| 家族 | 比较 | 样本 | 通过规则（预先写死） |
| --- | --- | --- | --- |
| A 安全 | S0 上 M3−M0 相对 RMSE | 稳定序列 | 点估计 ≤ 0.02，且 95% 上限 ≤ 0.05 |
| B 泄漏 | S6 上 M2−M0、M3−M0 | 未来跳变序列 | 不得显著为负（不能优于持久性） |
| C 残差 | 可见变化的 S1/S2/S4/S5 上 M2−M1 | 按机制分开 | 只对预先预期 M2 有用的机制解释为支持；S1 不要求 M2 胜 |
| D 门 | 可见变化上 M3−M3c；稳定上 M3−M3c | 按机制分开 | 变化上显著为负且稳定上不显著变差，才允许说「开关有用」 |
| E 方差对照 | S3 上 M2−M0、M3−M0 | 方差变化序列 | 不把点预测优势当成功 |

M3−M2 只作附录。门值与真实可见变化、与 \(\phi\) 的相关只作描述，不作机制证明。

四种结局都有效：支持、仅部分机制支持、无差别、不利。不利必须全文保留。

### 9. 报告顺序（写论文时）

1. S6 泄漏：过不了则停止方法主张。  
2. S0 安全。  
3. 分机制的 M2 对 M1（C）。  
4. 分机制的 M3 对 M3c（D）。  
5. S3 作为「不是所有非平稳都该改点预测」的对照。  
6. 检测器相对真实变点的滞后与漏检，作为方法边界，不事后改 \(\tau\)。

### 10. 与真实数据的关系

本仿真通过 A–E 之前，**不上新的真实面板当主证据**。V2/V3 已有真实数字可在讨论中作为「覆盖不足时结论不可外推」的反例，不得再当正面结果。若仿真通过后再做真实数据，必须在训练前证明该来源检测器稳定/变化样本达到预先下限，否则该来源只标「不可估计」。
