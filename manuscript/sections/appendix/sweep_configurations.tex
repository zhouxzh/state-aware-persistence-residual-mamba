\subsection{Evaluated Mamba Configurations}

Four Mamba labels enter the completed benchmark.
S-Mamba is the reversible-normalized inverted forecasting backbone.
NS-Mamba-D adds three-way moving-average decomposition and sums component forecasts.
MS-Mamba-MD adds multiple downsampled temporal scales with mean scale fusion.
PMS-Mamba-PD replaces the inverted branch at each scale with a temporal patch-token Mamba branch while retaining decomposition and mean fusion.
Other architecture labels described by the implementation are not included in the 336 trained-model cells and are not used to support the reported comparison.

\subsection{Deterministic Reference and Dataset Preparation}

The manuscript result generator computes last-value errors using the same 70/10/20 split, test origins, all-lead pooling, and training-difference RMSSE denominator as the learned models.
It writes 24 rows to \path{manuscript/data/last_value_baseline.csv}, including the origin count and scalar forecast count for each nominal length.
No fitted parameter or test-informed choice enters this calculation.

The current Exchange target can be checked against its local long-format input with
\begin{verbatim}
conda run -n mamba python scripts/prepare_exchange_uk.py --check
\end{verbatim}
The script selects the \texttt{United Kingdom} rows, drops missing quoted values, sorts the dates, and verifies exact equality with \path{data/Exchange/exchange_rate.csv}.

\subsection{Evidence and Regeneration}

The manuscript build reads the four final trained-model matrices directly from \path{results/} and the two target files from \path{data/}.
Running \texttt{make -C manuscript pdf} first regenerates the last-value rows, Table~\ref{tab:benchmark-family-summary}, Table~\ref{tab:benchmark-model-ranking}, Table~\ref{tab:benchmark-optuna-protocol}, and Figure~\ref{fig:benchmark-family-comparison}.
Generation fails if a trained model--horizon row is missing, a run is incomplete, selection/test flags are wrong, a metric is non-finite, balanced RMSSE does not match its term groups, a final score disagrees with selected-parameter metadata, or a last-value target is missing.

The GLD baseline reproduction bundle is rooted at \path{scripts/gld_baseline_optuna_bundle/}; its run archive is the \texttt{reproduced\_artifacts} subdirectory.
It contains checkpoints, predictions, targets, metrics, and run metadata for all 120 baseline rows.
Because stochastic replay changes 30 metric vectors, the frozen \path{results/gld_baseline_optuna_best.csv} remains the source for the descriptive GLD table; the replay difference is disclosed in the limitations rather than silently replacing the selected-run result.

The repository currently lacks a public archival tag or DOI containing the exact manuscript state, and the original experiment hardware record is incomplete.
These items remain prerequisites for an external reproducibility claim and formal submission package.
