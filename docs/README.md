# Technical Documentation

This directory is the manuscript-supporting technical record for the active
target-only financial forecasting releases. It contains no manuscript source and
does not treat historical mixed S/MS outputs as current evidence.

| Document | Purpose |
| --- | --- |
| [data_reference.md](data_reference.md) | Active v1 and v2 targets, dates, data hashes, and redistribution boundary. |
| [model_reference.md](model_reference.md) | Implemented Regime-Gated Mamba architecture, model roster, and ablations. |
| [evaluation_record.md](evaluation_record.md) | Current completion status, metrics, and claim boundaries. |
| [computational_profile.md](computational_profile.md) | Recorded v1/v2 matched CUDA forward-pass profiles and interpretation limits. |
| [reproducibility.md](reproducibility.md) | Rebuild, train, replay, report, and verification commands. |
| [evidence_registry.md](evidence_registry.md) | Claim-to-artifact map for technical writing. |
| [results_inventory.md](results_inventory.md) | What is active, local-only, and recoverably archived. |
| [repository_structure.md](repository_structure.md) | Directory ownership and supported commands. |
| [final_evaluation_record.md](final_evaluation_record.md) | Acceptance gate for a publication-ready release. |
| [ace2_code_agent_experiment_plan_20260812.md](ace2_code_agent_experiment_plan_20260812.md) | Retained audit planning record; not an active protocol. |

Use `financial_s_only_v1` for the original four target-only panels and
`financial_s_only_v2` for the independent-target expansion. They must be analyzed
and reported separately. Both are retrospective releases because their 2023--2026
evaluation targets have already been viewed.
