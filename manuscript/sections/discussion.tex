\section{Discussion and Limitations}

This manuscript is currently a draft after the Optuna-tuned non-Mamba baseline sweep and the completed Mamba-family Optuna search.
The main limitation is no longer whether strong optimized non-Mamba baselines exist; that part is complete.
The remaining limitation is dataset scope.
GLD provides a useful nonstationary financial testbed, but one dataset is not enough to establish general forecasting superiority.
After GLD experiments are complete, the method should also be tested on standard long-horizon forecasting datasets such as Exchange, Weather, ETT, Electricity, and Traffic.

The second limitation is split sensitivity.
Financial time series evaluation can change substantially with different historical periods.
The final manuscript should report the exact date range, train-validation-test boundaries, random seeds, and whether validation or test windows use lookback context from earlier splits.

The third limitation is architectural scope.
The current Optuna bundle only covers four completed Mamba-family variants, so it supports a clean comparison on GLD but not a broader claim about the entire Mamba design space.
The present results suggest that the strongest Mamba configuration depends on lookback selection, moving-average window, and multi-scale structure, so future changes should be justified by improved metrics rather than by architectural novelty alone.
The baseline analysis also raises the bar for improvement: any new Mamba variant has to preserve the RMSSE advantage while keeping price-scale RMSE and MAE stable at short, middle, and long horizons.
