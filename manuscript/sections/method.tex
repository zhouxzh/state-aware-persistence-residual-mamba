\section{Forecasting Models}

\subsection{Paired Forecasting Tasks}

Let $\mathbf{X}_{t-L+1:t}\in\mathbb{R}^{L\times C}$ denote the observations available at forecast origin $t$, and let $Y_{t+1:t+H}\in\mathbb{R}^{H}$ denote the future path of one target series.
For each financial panel, the S task sets $C=1$ and supplies only the target history.
The paired MS task supplies all $C>1$ panel variables, with the target stored in the last channel.
Although MS models emit one forecast per input channel internally, training loss and evaluation select only this final target channel.
Thus, MS means multivariate input to single-target prediction rather than unrestricted multivariate forecasting.
The horizon set is
\begin{equation}
    H\in\{1,5,20,60,120,252\}.
\end{equation}
A separate model is fitted for every task and horizon; its lookback length $L$ and other hyperparameters are selected using validation data only.

\subsection{Selective State-Space Backbone}

A discretized linear state-space model updates a latent state $\mathbf{h}_t$ and produces an output $\mathbf{y}_t$ as
\begin{equation}
    \mathbf{h}_t=\bar{\mathbf{A}}\mathbf{h}_{t-1}+\bar{\mathbf{B}}\mathbf{x}_t,
    \qquad
    \mathbf{y}_t=\mathbf{C}\mathbf{h}_t.
\end{equation}
Mamba makes the discretization and readout input-dependent, producing selective parameters $\bar{\mathbf{A}}_t$, $\bar{\mathbf{B}}_t$, and $\mathbf{C}_t$ \cite{mamba}:
\begin{equation}
    \mathbf{h}_t=\bar{\mathbf{A}}_t\mathbf{h}_{t-1}+\bar{\mathbf{B}}_t\mathbf{x}_t,
    \qquad
    \mathbf{y}_t=\mathbf{C}_t\mathbf{h}_t.
\end{equation}
The repository encoder applies independent forward and reverse Mamba scans, sums their outputs, and uses residual connections, layer normalization, and a feed-forward sublayer.

\subsection{S-Mamba}

S-Mamba uses reversible normalization and inverted variable tokens \cite{smamba}.
For sample $b$ and variable $c$,
\begin{equation}
    \mu_{b,c}=\frac{1}{L}\sum_{t=1}^{L}X_{b,t,c},
    \qquad
    \sigma_{b,c}=\sqrt{\frac{1}{L}\sum_{t=1}^{L}(X_{b,t,c}-\mu_{b,c})^2+\epsilon},
\end{equation}
\begin{equation}
    Z_{b,t,c}=\frac{X_{b,t,c}-\mu_{b,c}}{\sigma_{b,c}}.
\end{equation}
The entire normalized history of variable $c$ is projected to one token,
\begin{equation}
    \mathbf{e}_{b,c}=W_{\mathrm{emb}}\mathbf{z}_{b,:,c}+\mathbf{b}_{\mathrm{emb}},
    \qquad
    \mathbf{E}\in\mathbb{R}^{B\times C\times d_{\mathrm{model}}}.
\end{equation}
After bidirectional Mamba encoding, a linear head produces $H$ values per variable and the window transformation is reversed.
In S tasks, the encoder receives one variable token and therefore cannot model cross-series relations.
In MS tasks, it receives all panel variables and can represent associations among their histories, although the paired design does not establish that any such association is causal.

\subsection{Decomposition and Multi-Scale Variants}

NS-Mamba-D uses standard reversible normalization and a three-way moving-average decomposition.
With centered moving average $\operatorname{MA}_{m}(\cdot)$ and boundary replication,
\begin{align}
    \mathbf{Z}^{\mathrm{tr}} &= \operatorname{MA}_{m}(\mathbf{Z}), \\
    \mathbf{R}^{0} &= \mathbf{Z}-\mathbf{Z}^{\mathrm{tr}}, \\
    \mathbf{Z}^{\mathrm{se}} &= \operatorname{MA}_{m}(\mathbf{R}^{0}), \\
    \mathbf{Z}^{\mathrm{re}} &= \mathbf{R}^{0}-\mathbf{Z}^{\mathrm{se}}.
\end{align}
Independent S-Mamba branches forecast the three components, and their normalized forecasts are summed before inverse normalization.
The labels trend, seasonal, and residual name architectural components only; they are not identified economic processes.

MS-Mamba-MD first concatenates the three components along the variable dimension and forms average-pooled temporal scales $s\in\mathcal{S}$:
\begin{equation}
    \mathbf{V}_{s}=\mathcal{P}_{s}\!\left(
        \operatorname{concat}_{C}[\mathbf{Z}^{\mathrm{tr}},\mathbf{Z}^{\mathrm{se}},\mathbf{Z}^{\mathrm{re}}]
    \right).
\end{equation}
One inverted-token Mamba branch processes the $3C$ component tokens at each scale.
Its component forecasts are summed within variable, and the frozen MD configuration averages forecasts over scales.

The patch variant, PMS-Mamba-PD, retains the decomposition and scale construction.
It replaces each inverted-token branch with temporal patch tokens.
For component channel $k$, patch length $p$, and stride $r$, patch $j$ is embedded as
\begin{equation}
    \mathbf{e}_{j,k}^{(s)}=
    W_p\operatorname{vec}\!\left(\mathbf{V}_{s,j:j+p-1,k}\right).
\end{equation}
Mamba scans the patch sequence, a flattened head maps it to $H$ values, and component and scale forecasts are combined by sums and means, respectively.

\subsection{Learned and Statistical Comparators}

The learned comparison set contains DLinear, NLinear, PatchTST, TimesNet, and iTransformer \cite{dlinear,patchtst,timesnet,itransformer}.
These models cover decomposition-based and last-value-centered linear mappings, temporal patch attention, two-dimensional temporal modeling, and inverted variable-token attention.
All learned models use the same task-specific optimization budget and final seed set.

Four non-neural references address the strong persistence of financial levels.
Last-value repeats $Y_t$ for every lead.
Random-walk-with-drift extrapolates the average change from the first available observation through origin $t$.
ARIMA order $(p,d,q)$ is chosen on training data by minimum AIC over $d\in\{0,1\}$ and $p,q\in\{0,1,2,3\}$, excluding ARIMA$(0,0,0)$.
For MS tasks only, VAR-difference selects a lag from 1 through 10 by training BIC, forecasts first differences of the complete panel, and accumulates the target differences back to levels.
Orders and lags are selected using training data only.
Coefficients are then estimated once from all pre-test training and validation observations; states are updated sequentially with newly observed test values without refitting coefficients at every origin.

\subsection{Training Objective}

All learned models minimize mean squared error on the scaled target channel:
\begin{equation}
    \mathcal{L}=\frac{1}{BH}\sum_{b=1}^{B}\sum_{h=1}^{H}
    \left(\hat{Y}_{b,h}-Y_{b,h}\right)^2.
\end{equation}
Each column is standardized using training data only.
Predictions and targets are transformed back to the target's original scale before evaluation.
