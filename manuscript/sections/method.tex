\section{Forecasting Models}

\subsection{Task Definition}

Let $\mathbf{X}_{t-L+1:t}\in\mathbb{R}^{L\times C}$ be a lookback window of length $L$ and let $\mathbf{Y}_{t+1:t+H}\in\mathbb{R}^{H\times C_o}$ be the forecast target.
All experiments use single-target S mode, so $C=C_o=1$.
Both tasks use
\begin{equation}
    H \in \{1,3,5,7,14,30,60,90,120,180,270,360\},
\end{equation}
Each horizon has a separately trained model and can use a model-specific lookback $L$ selected on validation data.

\subsection{Selective State-Space Backbone}

A linear state-space model maps input $\mathbf{x}_t$ to latent state $\mathbf{h}_t$ and output $\mathbf{y}_t$ through
\begin{equation}
    \mathbf{h}_t=\bar{\mathbf{A}}\mathbf{h}_{t-1}+\bar{\mathbf{B}}\mathbf{x}_t,
    \qquad
    \mathbf{y}_t=\mathbf{C}\mathbf{h}_t.
\end{equation}
Mamba makes the discretization and readout input-dependent, yielding selective parameters $\bar{\mathbf{A}}_t$, $\bar{\mathbf{B}}_t$, and $\mathbf{C}_t$ \cite{mamba}:
\begin{equation}
    \mathbf{h}_t=\bar{\mathbf{A}}_t\mathbf{h}_{t-1}+\bar{\mathbf{B}}_t\mathbf{x}_t,
    \qquad
    \mathbf{y}_t=\mathbf{C}_t\mathbf{h}_t.
\end{equation}

\subsection{S-Mamba Forecasting Encoder}

S-Mamba first applies reversible window normalization \cite{smamba}.
For sample $b$ and variable $c$,
\begin{equation}
    \mu_{b,c}=\frac{1}{L}\sum_{t=1}^{L}X_{b,t,c},
    \qquad
    \sigma_{b,c}=\sqrt{\frac{1}{L}\sum_{t=1}^{L}(X_{b,t,c}-\mu_{b,c})^2+\epsilon},
\end{equation}
\begin{equation}
    Z_{b,t,c}=\frac{X_{b,t,c}-\mu_{b,c}}{\sigma_{b,c}}.
\end{equation}
The complete normalized history of each variable becomes one token:
\begin{equation}
    \mathbf{e}_{b,c}=W_{\mathrm{emb}}\mathbf{z}_{b,:,c}+\mathbf{b}_{\mathrm{emb}},
    \qquad
    \mathbf{E}\in\mathbb{R}^{B\times C\times d_{\mathrm{model}}}.
\end{equation}
A bidirectional encoder applies independent Mamba scans to the token order and its reversal, sums the two outputs, and then applies residual connections, layer normalization, and a feed-forward block.
The final token representation is projected to $H$ values and transformed back to the original target scale:
\begin{equation}
    \hat{Y}_{b,h,c}=\sigma_{b,c}P_{b,c,h}+\mu_{b,c}.
\end{equation}

In the present S-mode benchmark, $C=1$ and the inverted encoder therefore receives one variable token.
The bidirectional variable scan cannot represent cross-variable dependence in this setting.
This is a property of the experimental task, not a change to the implementation, and it motivates the multivariate limitation discussed later.

\subsection{Decomposition Variant}

NS-Mamba-D applies standard reversible normalization and separates the normalized window into low-frequency, medium-frequency, and residual components.
Let $\operatorname{MA}_{m}(\cdot)$ denote a centered moving average with boundary replication and selected window length $m$:
\begin{align}
    \mathbf{Z}^{\mathrm{tr}} &= \operatorname{MA}_{m}(\mathbf{Z}), \\
    \mathbf{R}^{0} &= \mathbf{Z}-\mathbf{Z}^{\mathrm{tr}}, \\
    \mathbf{Z}^{\mathrm{mf}} &= \operatorname{MA}_{m}(\mathbf{R}^{0}), \\
    \mathbf{Z}^{\mathrm{re}} &= \mathbf{R}^{0}-\mathbf{Z}^{\mathrm{mf}}.
\end{align}
Three S-Mamba branches forecast the components independently and their normalized outputs are summed:
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{D}}
    =
    \mathcal{N}^{-1}\left(
        \sum_{q\in\{\mathrm{tr},\mathrm{mf},\mathrm{re}\}}
        \mathcal{F}_{\theta_q}(\mathbf{Z}^{q})
    \right),
\end{equation}
where $\mathcal{N}$ is reversible normalization and $\mathcal{F}_{\theta_q}$ is a forecasting branch.
The component labels describe the architectural bias; they are not asserted to be uniquely identifiable physical processes.

\subsection{Multi-Scale and Patch-Temporal Variants}

MS-Mamba-MD adds average-pooled temporal scales.
For scale set $\mathcal{S}$ and downsampling operator $\mathcal{P}_{s}$, the implementation concatenates the three component series along the variable dimension,
\begin{equation}
    \mathbf{V}_{s}
    = \mathcal{P}_{s}\left(
        \operatorname{concat}_{C}
        [\mathbf{Z}^{\mathrm{tr}},\mathbf{Z}^{\mathrm{mf}},\mathbf{Z}^{\mathrm{re}}]
    \right).
\end{equation}
A single scale-specific inverted branch $\mathcal{F}_{\theta_s}$ processes all $3C$ component tokens; there is not an independently parameterized branch for every component.
Its output is reshaped by component and summed,
\begin{equation}
    \mathbf{Q}_{s}=\mathcal{F}_{\theta_s}(\mathbf{V}_{s}),
    \qquad
    U_{s,c,h}=\sum_{q=1}^{3}Q_{s,q,c,h}.
\end{equation}
The selected MD configuration then averages the scale forecasts,
\begin{equation}
    \hat{\mathbf{Y}}_{\mathrm{MD}}
    =
    \mathcal{N}^{-1}\left(
        \frac{1}{|\mathcal{S}|}\sum_{s\in\mathcal{S}}\mathbf{U}_{s}
    \right).
\end{equation}

PMS-Mamba-PD retains the same concatenated component representation and shared branch per scale, but replaces the inverted branch with a temporal patch-token branch.
For component channel $k$, patch length $p$, and stride $r$, the branch embeds patch $j$ as
\begin{equation}
    \mathbf{e}_{j,k}^{(s)}
    =
    W_p\operatorname{vec}\left(\mathbf{V}_{s,j:j+p-1,k}\right),
\end{equation}
applies Mamba over the patch index, projects each component channel to $H$ values, and sums the three component outputs before mean fusion across scales.
Unlike the one-token S-Mamba encoder in S mode, this branch presents a temporal token sequence to the selective state-space operator.

\subsection{Deterministic Reference Forecast}

The last-value reference repeats the most recent observation available at forecast origin $o$ for every lead $h$:
\begin{equation}
    \hat{Y}_{o,h}^{\mathrm{LV}}=X_o,
    \qquad h=1,\ldots,H.
\end{equation}
It has no trainable parameters, lookback selection, or validation step.
The reference is evaluated on exactly the same test origins and lead-time aggregation used for the learned models.

\subsection{Training Objective}

All models minimize mean squared error on the scaled training target:
\begin{equation}
    \mathcal{L}
    =
    \frac{1}{BHC_o}
    \sum_{b=1}^{B}\sum_{h=1}^{H}\sum_{c=1}^{C_o}
    \left(\hat{Y}_{b,h,c}-Y_{b,h,c}\right)^2.
\end{equation}
Inverse transformation is enabled for evaluation, so saved predictions, targets, and reported errors are on each target's original scale.
