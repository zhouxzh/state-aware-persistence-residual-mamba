\section{Introduction}

Financial level forecasting is difficult not simply because prices and rates are persistent, but because the representation useful in one local window can become poorly scaled or emphasize the wrong time scale in another.
Location, volatility, and cross-series dependence can all change while the prediction target remains a level.
An architecture for this setting should therefore preserve local scale information, separate slow and rapidly changing structure without treating either as an identified economic mechanism, and retain temporal order at more than one resolution.

Mamba supplies an input-selective state-space recurrence with a linear recurrent scan \cite{mamba}.
However, the tokenization choice determines what that scan can model.
In an inverted variable-token encoder, each whole variable history is embedded into one token \cite{smamba,itransformer}.
For a univariate task, the resulting token sequence has length one: the Mamba block can transform the embedded history, but it cannot perform a recurrence across temporal tokens.
This implementation-level limitation motivates a temporal-patch state-space model rather than another variable-token variant.

We construct PMS-Mamba (patch multi-scale Mamba), which applies reversible window normalization, an additive moving-average decomposition, mean-pooled temporal resolutions, and bidirectional Mamba encoders over ordered patches.
The model is designed around three representation hypotheses: slow and high-frequency variation should not be forced through the same branch; a local perturbation should be smoothed rather than amplified before coarse-scale encoding; and a univariate state-space model should receive a sequence of temporal patches rather than a single variable token.
These are architectural hypotheses, not assumptions that financial markets follow a fixed trend--seasonal--residual process.

The four financial panels are used first to test whether the proposed representation problem is present in the data.
They span foreign exchange, Treasury yields, cross-asset prices, and cryptoassets, and produce paired target-only and multivariate-input tasks.
The analysis uses only training and validation observations to characterize nonstationarity and distribution shift; it does not use the protected 2023--2026 targets to select the narrative.

The contributions are:
\begin{itemize}
    \item an implementation-grounded diagnosis of the single-token limitation of inverted Mamba encoders for univariate forecasting;
    \item PMS-Mamba, which joins additive decomposition, multi-scale pooling, temporal patches, and bidirectional selective state-space encoding in one financial-level forecaster;
    \item representation-level propositions for additive component preservation, pooling stability, and bounded fixed scale fusion, with proofs in Appendix~\ref{app:theory}; and
    \item a data analysis across four financial panels together with a leakage-controlled evaluation design for testing the model against persistence, statistical, and neural references.
\end{itemize}

This version reports the model, its representation properties, and selection-safe data analysis.
The final out-of-sample outcome matrix is not yet available, so the manuscript makes no claim that PMS-Mamba improves forecasting accuracy.
